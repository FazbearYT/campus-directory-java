# Campus Directory

Учебное приложение «Справочник контактов» для последовательного выполнения лабораторных работ по Java.

## Вариант

Вариант 4: справочник контактов с последующим хранением данных в префиксном дереве.

## Требования

- JDK 21 или новее
- Gradle Wrapper

## Состояние

Разработка лабораторной работы №1 ведётся в ветке `lab1`.
